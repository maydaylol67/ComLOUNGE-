Public Hosting & Multi-User Testing Guide

Deploy for 15-50 users (24h/day, 5-7 days/week)

1 Free Hosting Options (Vercel or Netlify)

For small user bases (15-50 users), free tier hosting on Vercel or Netlify will easily handle your traffic 24/7 without cost.

  • Vercel Drag & Drop: Save this single HTML file as index.html inside a folder. Go to Vercel Import and drag your folder directly to get a live URL in 10 seconds.
  • Netlify Drop: Visit Netlify Drop, upload your folder containing index.html, and receive a permanent custom web link.

2 Connecting Supabase Realtime Database

To connect real users together in real-time across different devices, set up a free project at Supabase.com and run this SQL query in your SQL Editor:

CREATE TABLE commuters (
  id TEXT PRIMARY KEY,
  name TEXT NOT NULL,
  tag TEXT NOT NULL,
  status TEXT DEFAULT 'in-lounge',
  zone TEXT DEFAULT 'Main Sofa Lounge',
  custom_note TEXT,
  updated_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);

-- Enable Realtime Sync
ALTER PUBLICATION supabase_realtime ADD TABLE commuters;

3 Testing Multi-User Live Interaction

Once deployed live or testing locally:

  1. Open your live deployed link in Window #1 (e.g. Standard Chrome).
  2. Open the same URL in Window #2 (Incognito Mode) or on your mobile phone.
  3. Change your status in Window #1—notice the Auto-Sync and Refresh indicator update the heatmaps, occupancy metrics, and user wall across both sessions!
